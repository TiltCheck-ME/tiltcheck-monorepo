# Surgical Self-Exclusion (Renamed)

This documentation has moved to [Browser Game Filters — Technical Reference](browser-game-filters.md).

TiltCheck has retired the regulated phrase "self-exclusion" in client-side documentation to clearly distinguish local browser game filters from government-regulated or operator-enforced exclusion registers like GAMSTOP and NCPG.
