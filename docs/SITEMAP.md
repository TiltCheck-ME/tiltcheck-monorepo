# TiltCheck Site Map

## Dashboard Pages (Active)
- **[Home](/)**: Ecosystem hub and tool directory.
- **[QualifyFirst](/qualify)**: Earn crypto rewards by completing tasks.
- **[CollectClock](/bonus)**: Bonus cycle tracking and timer monitoring.
- **[Wallet Check](/wallet-check)**: Security scanner for EIP7702 and malicious approvals.

- **[JustTheTip](/justthetip)**: Non-custodial Discord tipping service.
- **[User Profile](/user)**: Manage linked accounts and earnings.

## RG v1 Discovery Lanes
- **[RG Tools v1 Plan](product/rg-tools-v1-plan.md)**: Cross-surface discovery map, dashboard ownership rules, and "where do I click?" QA checklist.
- **Session Brake / Safety Controls**: Extension sidebar for live action; dashboard `/dashboard?tab=safety` for durable controls; Discord for optional support delivery.
- **LockVault / AutoVault**: Dashboard `/tools/auto-vault` owns rules and review; extension links in-session vault actions back to the dashboard lane.
- **Buddy System**: Dashboard `/tools/buddy-system` owns partners and thresholds; Discord delivers support alerts.
- **Fairness + Trust**: Web tool explainers own definitions and evidence; extension shows concise verdicts with dashboard/web handoffs.
