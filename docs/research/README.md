# Research briefs

Research briefs in this directory are machine-generated artifacts for ops review.

## Rules

- Treat `unknown` as a valid result when the fetch did not produce enough evidence.
- Do not invent competitor facts to make a matrix look complete.
- Do not hand-edit matrix cells unless you also update the Meta sources that justify the change.
- Sidecar `.tasks.json` files are the source for proposed task merges into ops workflows.

## Usage

- Review the `Meta` section first so the source URLs and fetch outcomes are explicit.
- Review `Gaps` before trusting a brief as complete.
- Re-run the generator instead of patching old output by hand whenever possible.
